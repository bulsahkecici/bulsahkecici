# Bulşah Keçici

**Machine Learning Engineer / Applied AI Engineer**

I build machine-learning systems that connect **data, models, evaluation, and working software**. My background in statistics shapes how I approach validation and evidence; my engineering work focuses on turning that into reproducible, testable systems.

I am especially interested in **MLOps, applied AI systems, retrieval and knowledge pipelines, speech, and computer vision**.

## Featured work

### [End-to-End MLOps — IEEE-CIS Fraud Detection](https://github.com/bulsahkecici/end-to-end-mlops-fraud-detection)
End-to-end ML lifecycle project with temporal validation, a shared training/serving `sklearn.Pipeline`, LightGBM, MLflow Model Registry, candidate → champion promotion gates, FastAPI inference, Docker, monitoring, tests, and reverse-proxy rate limiting.

### [Meeting Bridge — Turkish ⇄ English](https://github.com/bulsahkecici/live-meeting-translator)
Bidirectional meeting-assistance system for macOS and Windows. Turkish speech can be translated and routed back to conferencing software as English audio, while incoming English speech is handled separately and displayed as Turkish subtitles. Uses MLX Whisper / Faster Whisper, DeepL, TTS, and virtual audio routing.

### [TunnelBookAI](https://github.com/bulsahkecici/tunnekbookai_v1)
Evidence-grounded technical publishing and knowledge pipeline with unified ingest, provenance, canonical evidence, retrieval, quality gates, claim-level review, controlled revision, and reproducible freeze/audit stages.

### [PaperCrawler](https://github.com/bulsahkecici/paper-crawler-agent)
Technical source discovery and acquisition pipeline using scholarly and institutional sources, provenance tracking, SHA-256 verification, deduplication, authority classification, safe acquisition, and structured handoff to TunnelBookAI.

### [Multi-Platform Dental Application](https://github.com/bulsahkecici/MultiPlatformDentalApp)
Multi-client software system with a Node.js/Express/PostgreSQL backend, Angular web client, WPF desktop client, Flutter mobile client, Socket.IO updates, RBAC, MFA, audit logging, and deployment documentation.

### [Vehicle Speed Detection](https://github.com/bulsahkecici/VehicleSpeedDetection)
Computer-vision desktop application using YOLOv8, OpenCV, tracking, motion-based speed estimation, SQLite logging, and a PyQt interface.
